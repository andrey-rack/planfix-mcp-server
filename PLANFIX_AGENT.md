### Зв'язок сутностей
```
Contact (клієнт/компанія)
  └── Lead Task (лід, template 3813) — перший контакт, продаж
        └── Sell Task / Project Task (template 6018) — активний проєкт
              ├── Child Tasks (підзадачі виконання)
              └── Аналітика (datatag entries) — фінанси
```

## Типові Query-ланцюжки

### "Інформація по клієнту [ім'я]"
```
1. planfix_search_contact(name="[ім'я]")
2. planfix_get_contact(contactId=...)        → повні дані, lastCommentDate
3. planfix_get_contact_comments(contactId=..., pageSize=5)  → остання взаємодія
```

### "Аналітика / економіка проєкту [назва]"
```
1. planfix_search_task(taskTitle="[назва]") або planfix_search_project(name="[назва]")
2. planfix_get_task(taskId=...)              → опис, дати, статус
3. planfix_get_task_analytic(taskId=...)    → Покупка:послуги (виручка) + виплати (собівартість)
```

Фінансова формула:
- **Виручка** = сума по "Покупка: послуги" (поле Загальна сума або Факт оплати грн)
- **Собівартість** = сума по "Контроль виплат фахівцям" + "Контроль виплат партнерам"
- **Маржа** = Виручка − Собівартість

### "Задачі людини [ім'я / email]"
```
1. planfix_search_manager(email="[email]") → managerId
2. planfix_list_tasks(assigneeId=..., status="active")
```

### "Коли останній контакт по ліду [назва]"
```
1. planfix_search_lead_task(name="[назва]") → taskId
2. planfix_get_task_comments(taskId=..., pageSize=1)  → перший результат = останній коментар = останній контакт
```
Або швидше:
```
1. planfix_search_contact(name="[клієнт]") → contactId
2. planfix_get_contact(contactId=...)       → lastCommentDate (без додаткових запитів)
```

### "Покажи ліди / проєкти [фільтр]"
```
planfix_list_tasks(
  templateId=3813,        # для лідів
  status="active",
  searchText="[опційно]"
)
```

### "Активні проєкти відділу DEV"
```
planfix_list_tasks(templateId=6018, status="active", searchText="DEV")
```

## Форматування відповідей

- **Суми:** завжди вказувати валюту. 57 756 грн або $1 375
- **Дати:** формат dd.mm.yyyy. Якщо є час — dd.mm.yyyy HH:MM
- **Посилання:** завжди додавати url до задачі/контакту
- **Аналітика проєкту:** показати таблицю: Послуга | Годин | Ставка | Сума | Дата оплати | Факт
- **Список задач:** показати нумерований список з url і датами

## Важливі правила

1. **Фільтр по задачах** — для `planfix_get_task_analytic` і `datatag/entry/list` використовувати `taskId` (не `task.id`)
2. **lastCommentDate у контакті** — це дата останнього контакту, не треба окремо читати коментарі якщо потрібна тільки дата
3. **Пошук задачі** — `planfix_search_task` повертає останню задачу з такою назвою. Якщо потрібна точність — використати `planfix_list_tasks` з `searchText`
4. **Template IDs** — використовувати для фільтрації за типом задачі (лід vs проєкт vs внутрішня)
5. **Datatag записи** — всі без виключення прив'язані до конкретної задачі через `taskId`
